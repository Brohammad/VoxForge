# Demo Script — 60-Second Showcase

**For:** Twitter/X, LinkedIn, Reddit, interview screen-share opener  
**Record on:** https://voxforge.brohammad.tech (real product, not slides)

Lead with speak → cite → replay → escalate. Do not lead with mock latency numbers.

## Shot list

1. **[0–8s] Problem** — landing page.  
   Voice-over: "Voice-agent platforms are expensive and opaque. This is VoxForge — self-hosted voice AI you can operate yourself."

2. **[8–22s] Live call** — `/demo` → **Start talking** (or **Run trust loop** if you cannot use a mic).  
   Voice-over: "Same production pipeline: knowledge, tools, evaluation, replay."

3. **[22–38s] Grounding** — trust-loop / call results: FAQ citation + session ID.  
   Voice-over: "The agent grounded the refund answer in a document, not a hallucinated policy."

4. **[38–50s] Operations** — **Open replay**, then **Open inbox**.  
   Voice-over: "Operators inspect the turn, scores, and pick up the handoff."

5. **[50–60s] Close** — end card.  
   Voice-over: "Clone it. Deploy in 15 minutes."

## End card (on screen, last 10s)

```text
VoxForge — self-hosted voice AI
Demo  github.com/Brohammad/VoxForge
Live  voxforge.brohammad.tech/demo
```

## Captions

Burn in captions. Silent autoplay is the default on Twitter and LinkedIn.

Suggested lines:

- "Self-hosted voice agent — no per-minute platform fee"
- "Cite → replay → human handoff"
- "MIT · live demo · clone in 15 min"

## Recording tips

- 1920×1080, Chrome, dark mode; hide bookmarks
- Demo account already logged in on a second tab if replay requires it
- Export 16:9 MP4 under ~80MB; add the end card before posting
- See [recording-checklist.md](recording-checklist.md)
